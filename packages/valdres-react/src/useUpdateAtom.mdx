# useUpdateAtom

```ts
useUpdateAtom<Value>(atom: Atom<Value>, store?: Store):
    (update: AtomUpdater<Value>) => void
```

Returns an updater callback without subscribing the component. This is the only
React hook that treats a function argument as an Atom updater.

```tsx
function IncrementButton() {
    const updateCount = useUpdateAtom(countAtom)
    return <button onClick={() => updateCount(value => value + 1)}>+</button>
}
```
