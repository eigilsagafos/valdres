# useSetAtom

```ts
useSetAtom<Value>(atom: Atom<Value>, store?: Store): (value: Value) => void
```

Returns an exact-value setter without subscribing the component. Function values
are stored as values and are never invoked as updaters.

```tsx
function ClearButton() {
    const setCount = useSetAtom(countAtom)
    return <button onClick={() => setCount(0)}>Clear</button>
}
```

Use `useUpdateAtom` when the next value depends on the current value.
