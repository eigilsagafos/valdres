# useResetAtom

```ts
useResetAtom<Value>(atom: Atom<Value>, store?: Store): () => void
```

Returns a callback that resets an Atom in the selected Store. In a child scope,
resetting removes the local value and restores live parent inheritance.

```tsx
function ResetButton() {
    const resetCount = useResetAtom(countAtom)
    return <button onClick={resetCount}>Reset</button>
}
```
