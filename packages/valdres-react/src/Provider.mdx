# Provider

```ts
<Provider store: Store>{children}</Provider>
```

`Provider` borrows a required `Store` and makes it available to hooks below it.
It never creates, initializes, scopes, or disposes a Store. The code that owns
the Store is responsible for its complete lifecycle.

```tsx
import { store } from "valdres"
import { Provider } from "valdres-react"

const appStore = store()

export function App() {
    return (
        <Provider store={appStore}>
            <Main />
        </Provider>
    )
}
```

Nested Providers select the nearest Store. To use a scope, create it outside
render and pass it through another Provider:

```tsx
const editorStore = appStore.scope("editor")

<Provider store={appStore}>
    <Provider store={editorStore}>
        <Editor />
    </Provider>
</Provider>
```
