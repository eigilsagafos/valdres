# useValue

```ts
useValue<Value>(state: State<Value>, store?: Store): Value
```

Reads an Atom or Selector and re-renders when its synchronous value changes. By
default it uses the nearest Provider. Pass an exact Store as the second argument
when the component must target another Store.

```tsx
const greeting = selector(get => `Hello, ${get(nameAtom)}!`)

function Greeting() {
    return <h1>{useValue(greeting)}</h1>
}
```

The server-rendering path uses Valdres' isolated hydration reader, so it does
not turn a server read into a live client subscription.
